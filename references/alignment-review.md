# 透明度、对位与接缝

本文件处理已有素材的几何与透明度。完整形体和隐藏结构由图像编辑／生成补齐；处理后的素材仍按[验收标准](quality.md)在实际软件检查。

## 真实透明度

优先使用原生 RGBA。画出来的棋盘格不是透明背景。去底前观察真实前景是否含有同色衣料、高光或细线，保留孔洞、细丝和半透明结构，不把所有轮廓填成实心。

`extract_matte.py` 用于**饱和纯色底**，只处理 alpha 与必要的窄边颜色污染：

```text
python scripts/extract_matte.py --input project/candidate.png --output project/assets/part.png --matte-color blue --edge-radius 2
```

底色按实际候选选择，支持命名饱和色及 `R,G,B`、`#RRGGBB`；中性白／灰底会被拒绝。可用 `--protect` 指定已观察的前景保护图；保护图须同尺寸，L 值或 RGBA alpha ≥128 的区域保持原像素。不要整图保护来掩盖不确定性。

`--edge-radius 0` 禁用边缘 RGB 修正，其他阈值查看 `--help` 后按证据调整。输出 RGBA、alpha、去底区域、边带、黑白底预览和报告。算法不能辨认同色前景，不适用于普遍的半透明抠像；处理后检查颜色冲突、细线及所有孔隙。

## 回到原图坐标

记录原图画布、参考裁切和观察地标。生成图片尺寸或透明包围盒不代表原物体大小。

`registration` 使用以下一种方式：

- `frame:[x0,y0,x1,y1]`：把候选的整个画布映射到此矩形，包含透明余量，可分别缩放宽高。
- `landmarks:{"asset":[[x,y],...],"canvas":[[x,y],...]}`：用对应点定位。默认 `method:"similarity"`，至少两个不同点；`"affine"` 至少三个不共线点，只用于合理的比例／投影变化。
- 需要镜像时在 `registration` 内明确设置 `allow_reflection:true`；非对称装饰、线条与光照仍需检查。

从原始候选计算每次变换，避免重复采样。共用 `asset_pipeline.warp_rgba`，它在预乘 alpha 后采样，缩小时先滤波，防止透明 RGB 污染和细线断裂。

重建后或已定位素材设 `coordinate_space:"source_canvas"`，要求原图尺寸与单位变换；原图保留区也不随生成候选变换。相同画布只代表坐标容器一致，容器内的形体仍需对照。

## 当前复合的原图对照

在 `project.json` 配置 `alignment_review`，每次 `compose` 会从当前状态复合创建新对照，并在报告中给出路径。有独立背景时比较完整复合，否则将原图与候选分别置于相同中性底上，不用原图填补候选空白。

`regions` 是 `{id,box:[x0,y0,x1,y1]}` 列表；可选 `reference_points`、`observed_points` 指向源点和当前观察点文件，`max_error_px` 是项目容差，`pairs` 为 `{id,a,b}` 点对列表。首次可只生成区域对照；缺少有效核验点时数值检查保持待查。

源点文件：

```json
{
  "source_sha256": "实际原图哈希",
  "points": [{"id":"anchor","xy":[0,0],"role":"check","part":"part"}]
}
```

当前观察点文件：

```json
{
  "candidate_sha256": "本次候选哈希",
  "points": [{"id":"anchor","xy":[0,0],"evidence":"本次实际观察依据"}]
}
```

示例中的零坐标仅表示字段类型，使用时按原图标定。点坐标以像素中心为准，左上像素中心是 `(0,0)`。先独立标定源点，再看候选；`role:"fit"` 与 `"check"` 分开，不能给拟合点改名充当核验点。不同表情沿用不变锚点，其变化结构另行判断。修正原标注后，复查使用旧点的变换。

也可单独运行 `python scripts/alignment_review.py alignment.json`；配置加 `source`、`candidate` 和新 `output` 目录。输入同尺寸并明确采用 sRGB 解释，嵌入 ICC 须先正确转换。工具输出并排、叠加、差异、闪切 HTML 及点距报告，不自动移动候选来评分。

整体同向偏移修平移；尺度／倾角不符修配准；端点已对齐但中间轮廓不同则修形体。线条消失或重影先检查像素来源、alpha 和层序，不盲目继续挪动。独立点合格后仍检查完整曲线、线宽和布局。

## 边缘与颜色接缝

| 问题 | 处理 |
| --- | --- |
| 真实外轮廓、结构线、遮挡线 | 保留原画线宽与抗锯齿，局部去污染或修复缺线，不整圈羽化。 |
| 同材质内的源图／补画接缝 | 对齐后，在两侧均不透明且没有结构线的许可窄带内混合颜色，保持最终 alpha。 |
| 柔边覆盖片 | 下方须有完整同材质底片，再局部调整覆盖片 alpha，单独记录边带和处理前版本。 |
| 阴影、褶皱、纹样位置错误 | 返回补画，不靠模糊消除造型差异。 |

两件仅沿切口对接时先补足重叠，不同时羽化两边制造透明缝。不统一膨胀、腐蚀、闭运算或模糊所有部件。接缝必须有实际颜色和透明度支撑，不能借透明像素的隐藏 RGB 填洞。具体蒙版与校色接口见[原图重建](source-reconstruction.md)。
