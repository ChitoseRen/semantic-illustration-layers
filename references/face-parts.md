# 面部与表情部件

用于需要拆分五官、独立视线或表情的立绘。按已约定的动画用途决定部件与状态，不自动扩充表情库。脸底始终有完整皮肤底色，线条、体积明暗和投影按[材质分层](material-layers.md)另存。

## 共用原图基准

先观察整张脸及双眼，再辨认眉、眼睑折线、眼窝阴影、眼线和发影。相邻的深色笔画不一定属于同一结构。逐件独立显示后，还要放回全脸检查身份特征、双眼间距、倾角、眉眼距离和嘴部位置。

所有面部附件沿用同一原图画布、比例与色彩参照。优先保留无需改变的可见五官，用补画完成底片、隐藏延伸和约定的新状态。不能把左右眼分别裁紧后独立居中。拟合点和独立核验点按[对位规则](alignment-review.md)分别记录。

## 拆分时检查什么

| 部件 | 必要内容与交界 |
| --- | --- |
| 脸／皮肤底片 | 覆盖发下及投影下的完整皮肤；移开独立五官后无旧五官残影，鼻部等真实体积仍保留在对应线条或光影层。 |
| 眼白 | 包含虹膜和眼睑移动会露出的部分；无虹膜残边、重复眼线及孔洞。 |
| 虹膜／瞳孔 | 保留自身形体与高光；独立视线需要足够隐藏范围，并有实际眼开口遮挡。 |
| 上下眼睑 | 眼线、睫毛与必要随动皮肤归属清楚，眼角与底片衔接完整。 |
| 眉 | 眉形和抗锯齿独立，移开后无旧眉；不夹带无关皮肤或眼睑折线。 |
| 嘴与口腔 | 按口型需求拆分，所有状态共用干净底片；牙齿、舌等仅在动画需要时细分。 |

先补齐接收底片，再检查覆盖件。皮肤按结构和运动归属，不用肤色阈值自动划分；底色范围不能沿发影边裁掉。混色边、贴片接缝及局部颜色变化按[原图重建](source-reconstruction.md)处理。

## 状态与动作

区分两种制作需求：开／闭眼或嘴型的图层替换，以及连续闭合、视线移动等形变需求。只有开闭两张图时，应说明提供的是替换素材；不能把缩放眼白当成连续眼睑形体。

表情附件保留原角色的眼型、左右差异和绘画风格。不变的锚点共用定位基准，随表情变化的形体按实际动作判断，不能强行固定所有面部比例。新状态应放回整张脸检查，避免单件合理、组合却改变神态。

按约定幅度检查端点、中间状态和恢复；需要独立视线时，让虹膜相对眼白移动并检查遮挡。底片残影应修在底片，不能靠加大覆盖件或减小幅度隐藏。修改脸底、眼开口或层序后，复查相关五官及状态，使用统一[验收标准](quality.md)。
